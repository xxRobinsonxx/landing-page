# React

1. Construir el proyecto ( npm run build )
2. Crear repositorio en gitHub y subirlo

# Render.com
1. Entrar cuenta y seleccionar opcion Static Site
2. Seleccionar metodo de despliegue de GitHub
3. En build command ingresar: npm install && npm run build
4. En Publish Directory escribir: dist
5. Finalmente click opcion Create Static Site.
